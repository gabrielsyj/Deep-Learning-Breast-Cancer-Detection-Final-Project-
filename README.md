# Deep-Learning-Breast-Cancer-Detection-Final-Project

## CM3070 Final Project

This project follows the **3.2 Deep Learning Breast Cancer Detection** template, implementing and critically evaluating a technical system against real-world criteria.  

The **central aim** is to assess how effectively CNN-based models detect breast cancer from mammograms.  
- Training is conducted on **CBIS-DDSM**.  
- External testing is performed on **INbreast** to evaluate robustness beyond a single dataset.  

By applying best practices from deep learning and medical imaging, this project advances beyond typical student implementations limited to a single baseline model.
